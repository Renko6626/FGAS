# 网页助手首次使用导引

用户已确认：默认就绪，只解释缺少的条件；沿用现有权限和模型配置。

## 方案与取舍

采用聊天窗口内的状态提示，不新增分步向导。已有本人 low 连接及公共模型时直接聊天；缺连接时由用户点击“启用网页助手”，创建既有 low 凭据。high 继续手动选择，不自动升级权限。

权限以“提交申请，需审批”“可直接办理，须先确认”说明，连接名及 low/high 放进助手设置。模型代号与个人 Key 同样放进设置。

公共模型缺失时，普通成员可联系管理员或使用个人 Key；管理员可跳转既有公共模型设置页。重新打开助手时读取最新配置。

空白会话提供查社团余额、查库存、整理垫付三个预填示例，不自动发送、不覆盖已有输入。设置完成同时要求有效连接和模型配置。

## 边界与验收

仅修改既有前端组件及相关导引文案；无新依赖、接口、存储或权限规则。保留已实现的会话提醒和桌面近全屏布局。运行前端类型检查、构建和差异检查，不做浏览器自动交互，不新增永久测试。
