# 导航与页面框架调整

用户已确认采用顶部业务区域、侧栏当前区域页面的方案，并授权实施。

- 目标：减少同时出现的入口，利用顶部空间，让日常资金和货物页面更容易找到。
- 比较：保留长侧栏并折叠分组改动较小，但仍需浏览完整功能清单；选定的顶部区域方案把侧栏缩减为当前区域的 1～4 项，跨区域时需先切换顶部。
- 顶部：工作台、资金、货物、基础资料、管理（仅管理员）；高度 64～72px，保留现有 LOGO。删除独立深色页名条，页面标题放入正文。
- 工作台含首页和按权限显示的审批；资金含流水、私账结算、账户；货物含库存、转移、目录、账户；基础资料含成员；管理含权限、附件及已启用的公共模型设置。
- 帮助入口打开快速了解，工具菜单提供导出台账及刷新，用户菜单提供当前账号、个人 Agent 连接及退出。
- 手机顶部导航可横向滚动，侧栏继续使用现有抽屉开关。
- 导航部分延用 Vue、Naive UI、hash 导航、现有权限与页面；不新增依赖、后端接口、持久化或导航记忆机制。盘点仍遵守原功能开关。
- 导航验证采用已有前端类型检查、构建和页面截图，不自动点击或填写页面，不新增永久测试。
