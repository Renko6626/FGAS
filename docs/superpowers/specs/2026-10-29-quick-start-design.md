# 快速了解

用户已确认：增加最低限度的纯前端单页，用小动画说明账户、仓库和转移，再引导使用网页 AI 或自己的 coding agent。

采用任务指南单页，替代长篇说明和逐按钮导览。页面解释资金/货物账户、来源到去向的转移、资金审批入账与货物确认完成的区别；用垫付100元到报销归零说明私账，明确负数为社团欠成员、正数为成员应交回。

入口为日常工作“快速了解”和首页短链接，不自动弹出。末尾打开现有网页助手并预填示例（不自动发送、不覆盖已有输入），或跳转现有 Agent 连接。助手关闭功能时仅显示连接入口及说明。

沿用 Vue、Naive UI、当前字体与配色；主视觉为账户间移动的钱/货物示意，分段横线组织内容，避免堆叠说明卡片。动画由用户切换示例步骤触发，支持减少动态效果和窄屏。无新依赖、后端、数据存储或进度追踪。仅示意数据，不生成业务记录。

验证：前端类型检查与生产构建、差异检查；按项目约定只做静态截图，不自动点击或填写，不新增永久测试。
