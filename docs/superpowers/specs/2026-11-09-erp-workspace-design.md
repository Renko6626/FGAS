# FGAS 成熟 ERP 工作界面实装设计

## 已确认的方向

用户确认以 ERPNext、Katana 的工作界面为参考，采用克制、现代、稳定的外观，不使用幻想指南账册化或艺术化边框方案。保留原 LOGO。2026-11-08 至 11-09 的独立样稿已确认总体布局、收紧后的密度、醒目的最近记录，以及金额／货物列在来源去向左侧的顺序。本轮用户要求补充待审批行的颜色强调，并开始准备实装。

样稿：`temp/erp-sample-20261108/`；画布项目 `e6334af8-59dd-48ad-a020-a5b478ded0d1`，资金列表 `629acdcb-bb5f-4427-b627-042d6af309a2`、首页 `1b83aac0-a810-4929-a476-46ecb07087d7`、详情 `7f64efc0-f494-4239-95bf-0d0c2e9d82ae`。正式采用样稿的结构与样式，演示数据及演示操作不进入生产代码。

## 范围

1. 现有顶部业务切换、区域侧栏和正文标题／操作区，采用紧凑样稿尺寸；增加桌面侧栏的手动收起，手机沿用抽屉展开。收起仅为界面状态，不增加数据库或服务端设置。
2. 资金流水、货物转移和首页最近记录共用记录展示组件及样式。
3. 首页按待办入口、资金／库存摘要、私账往来、最近记录组织；复用已有数据与筛选，不新增统计接口。
4. 资金、货物详情延用现有抽屉与业务处理，收紧分区，采用中性色；资料、附件、分录／关联记录与操作记录保持可访问。
5. 其他目录、设置和导出页面跟随统一字体、色彩、控件和基础表格样式，本轮不重做其业务布局。库存关系图、矩阵、仓库视图继续保留。

## 共用记录视图

统一的桌面列顺序：事项 → 金额／数量 → 来源 → 箭头 → 去向 → 状态／已有操作。箭头独占固定列；来源右对齐、去向左对齐。手机将来源、箭头、去向放到事项下方的固定三列，同时露出金额／数量及状态。

事项、货物名称和账户方向使用清晰的深色字；编号、时间、标签、操作人等为次要资料。货物名称与数量逐 SKU 对应，不把不同单位加成一个总量。多 SKU 沿用当前首两项及其余项提示，详情可查看全部。首页仍展示最近 10 笔及全部／资金／货物筛选，不将样稿的 5 笔演示记录固定到真实页面。

比较过的实现方式：

- **只共享 CSS**：改动最少，但表头、列顺序、箭头结构、手机布局仍要在三个模板分别维护。
- **共享展示组件及简单投影（采用）**：一处维护表格、行布局、对齐、状态和响应式，各业务保留原有权限和处理逻辑。只抽取这三处实际需要的内容，不做配置驱动的通用表格系统。

职责和依赖方向：

- `frontend/src/presentation/records.ts`：把现有资金、货物和首页记录投影为展示数据；调用已有金额／状态格式化函数，不决定权限、过账或库存变化。
- `frontend/src/components/TransferRecordList.vue`：接收展示行，渲染统一列、主体信息、状态和已有操作插槽，发出打开记录事件，不发业务 HTTP 请求。
- 现有 `TransferRecords.vue`、`StockTransferRecords.vue`：继续管理详情抽屉、权限相关提示及资金／货物特有操作。
- `DashboardView.vue`：继续管理首页数据、转移类别筛选和跳转；只替换重复的记录渲染。

展示行只需 `kind`、业务 `code`、事项／货物、日期与次要资料、金额／各 SKU 数量、来源和去向名称、原状态和状态文案。以这些已用字段为准；不引入通用列 Schema、查询状态、业务状态机或请求恢复机制。

## 待审批强调

已有资金／货物列表已含待审批着色，实装应把规则收敛进共用组件，使首页同步生效：`pending` 行使用浅暖色背景、左侧 3px 色条和明确的“待审批”状态文字；悬停、键盘聚焦及选中时继续可辨识。不使用闪烁或自动动画，不改变记录排序，不推断任何新的审批状态。已有完成报告待核实提示继续保留。

## 保留的行为

- `/api` Cookie 身份、用户角色、Agent 接入与权限判断不变。
- hash 页码、FT/ST/FA 定位及筛选参数不变。
- 资金批准／拒绝／冲销，货物申请／登记／确认完成／完成报告的含义与处理仍走现有组件和服务。
- 首页私账展示不自动净额抵扣；余额、数量和近 7 天统计使用原数据口径。
- 盘点仍停用；不修改数据库、后端接口、部署方式或依赖。
- 保留当前分支已完成但未提交的导航、CSV 预览及时间格式调整，不覆盖或回退。

本轮属于 UI 及展示代码收敛，不默认新增永久测试或扩展 CI。遇到具体生产逻辑变化或已发生问题时再判断必要的覆盖。无后端改动时不重跑后端全套测试。未发布前明确报告本地状态；本设计不授权生产部署。
