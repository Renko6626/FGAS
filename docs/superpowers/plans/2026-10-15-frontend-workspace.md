# 前端工作台第一批优化

**目标：** 按用户确认的方向，直接复用 fantasyguide 的原始字体、边框、分隔线和纹样样式，完成整体框架、工作首页和资金页面。

**实施：** 本会话直接实现。沿用 Vue 3、TypeScript、Naive UI、Vite 与现有 API；沿用现有 tab 切换并同步 URL hash，使页面可直接访问和截图，不增加路由库或状态管理依赖。当前工作区原本干净，使用 `feature/frontend-workspace` 分支保存修改，不自动提交、合并或推送。

**约束：** 不改后端、数据模型、审批和结算口径；不修改或清空数据库；不新增防御机制。货物、结算、盘点与基础资料接入统一外壳，其内部流程留给后续批次。文案用用户能理解的业务名称，避免装饰性拼接。样式和布局不新增永久测试。

## 实施任务

- [x] 整体框架：`App.vue` 增加分组侧栏、移动端导航、页面标题和收起的开发账号切换；`theme.ts` 与 `style.css` 统一主题、字体、状态、间距及响应式布局。
- [x] 首页：新增 `DashboardView.vue`，消费已有账户、资金和货物记录；显示公账余额、待审批与未完成转移，提供登记入口和近期业务日期记录。净余额不冒充逐笔未结金额。
- [x] 资金账户：整理 `CatalogView.vue` 的资金模式，以账户列表呈现，增加搜索、分类和筛选层次，保留货物模式和编辑权限；空状态提供明确操作指引。
- [x] 资金流水：`TransfersView.vue` 增加搜索、状态与业务日期筛选，突出两端、金额和状态；详情先展示业务事实，分录与原始审计信息按需展开。审批与冲销沿用原路径。
- [x] 资金登记：`TransferEditor.vue` 与 `AccountAvatar.vue` 接入统一视觉，保留来源、金额、去向和现有选择器；可选信息分层展示。
- [x] 验证：集中运行 `npm run build` 和 `git --git-dir=.fgas-git --work-tree=. diff --check`；若已有截图工具可用，仅导航截图，不自动点击、填表或运行交互验收。

## 复核重点

角色对应导航和审批操作仍准确；切换身份不保留旧身份详情；已停用账户仍参与历史余额；资金首页仅汇总公账；空数据、长名称和移动端仍可阅读；资金登记按钮可以在资金页面直接找到。

## 用户补充约束

直接使用 fantasyguide 原始样式，不自行设计类似风格；删除意义不明的圆角、印章、口号、问候语和重复的小字说明。保留金额方向、审批条件与输入限制等必要业务提示。原始资源及样式出处记录在 `frontend/public/fantasyguide/SOURCES.md`。
