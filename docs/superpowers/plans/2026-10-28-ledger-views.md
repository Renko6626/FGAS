# 资金流水与货物转移视图优化计划

**目标：** 将两页的双列卡片改为连续对齐的单据列表，详情默认收起；资金保留待审批入口，货物明确分开待审批、待完成，并以小问号解释状态。

**已确认方案：** 本会话用户确认的资金账簿与货物工作清单方案，以及 2026-10-28 货物用语约定。

**技术与边界：** 沿用 Vue 3、TypeScript、Naive UI 和现有 HTTP 查询/写入路径。仅调整前端布局、筛选展示和详情容器，不改模型、权限、库存计算或后端接口。保留现有未提交工作，直接在当前工作区增量修改，不提交或推送。

## 实施步骤

- [x] 统一筛选工具栏：主状态入口和搜索/更多筛选/登记按钮保持紧凑；资金的待审批、货物的待审批与待完成独立显示。问号提供悬停及键盘聚焦说明。排序仅复用现有接口能力，不做当前页伪全量排序。
- [x] 改造资金与货物记录：说明为阅读起点，日期/编号为次要信息，来源去向、金额或数量、状态/动作固定对齐；手机采用连续行，不回到独立卡片；保留单据定位与原有权限动作。
- [x] 详情默认收起，选中后从右侧展开。复用现有详情与办理逻辑，取消、冲销、关联及完整历史仍可查看。
- [x] 将登记按钮并入各页工具栏，去掉为单个按钮单独占据的外层空白。
- [x] 集中运行 `npm run build` 与 `git diff --check`；使用实际基准数据截图核对桌面、手机、资金待审批、货物待审批/待完成及深链接详情。遵守不自动点击或填表的限制，不新增永久测试、不运行重建数据库的后端测试。

## 核对重点

金额不因全局视图误标正负收支；多 SKU 数量保留各自单位；完成报告待确认不变成主单状态；抽屉内保持原审批/确认权限；原有目标编号和筛选可用；小屏不增加页面横向溢出。

## 实施结果

两页已改为连续行列表，详情为默认关闭的右侧抽屉。资金保留待审批入口及既有全量日期排序；货物分别筛选待审批、待完成、已完成，默认待完成。状态旁问号支持悬停及键盘聚焦说明。创建按钮并入工具栏。共享盘点组件仅做 props 适配，入口仍停用。小屏分页条的既有横向溢出已修正。

`npm run build`（TypeScript + Vite）与 `git diff --check` 通过，保留现有主包超过 500 kB 提示。源码与接口契约审阅通过；以现有基准数据截图核对桌面/手机、状态入口、普通用户和深链接详情，无页面脚本或 API 错误。未自动点击、填写表单或运行会重建数据库的后端测试；未修改后端、数据库或业务数据。
