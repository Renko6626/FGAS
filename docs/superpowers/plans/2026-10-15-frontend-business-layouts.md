# 前端头像、状态与业务页面整理

**目标：** 按用户要求统一来源头像、账户名称、箭头、去向头像及名称；状态增加醒目的背景色；继续整理货物、结算、盘点内部布局。

**范围：** 复用现有 Vue、Naive UI 和 API。仅改变显示、筛选、弹窗和信息展开方式，不改变业务状态、权限、资金/数量/结算规则，不增加后端接口、数据结构或依赖。继续采用 fantasyguide 原始主题，避免自造印章、圆角、slogan 和重复说明。

- [x] 共用显示：`AccountLabel.vue` 复用现有头像；`AccountRoute.vue` 从已加载账户目录取得头像，无头像仍显示首字。首页、资金流水、货物、结算及盘点流水统一使用。`style.css` 提供直角状态底色：成功绿、待审批黄、在途蓝、拒绝红、取消/冲销/结束灰。
- [x] 货物：列表保留日期、头像两端、数量和状态，资金关联及审批在详情分区查看；详情先展示货物与当前可操作项。新建先选两端、日期与货物明细，资金关联和补充信息按需展开。完成申请保留既有二次审批和整笔完成语义。
- [x] 结算：先选择私账，净余额和双向未结分别展示；报销、交回和结算历史分栏，历史匹配按需展开。编辑器将付款资料与逐笔匹配分区，保留新付款与追加已有付款两种模式。
- [x] 盘点：资金/货物分类和盘点列表为默认页，新建与修改说明使用弹窗。进入详情后看状态、专属端点与转移记录；结束仍允许补录，新增盘盈/盘亏仍创建普通转移。
- [x] 集中验证：`npm run build`、`git --git-dir=.fgas-git --work-tree=. diff --check`；只做现有页面桌面/手机截图，不自动点击、填表或提交业务，不清库。无需为样式或布局新增永久测试。

**实施分工：** 主 agent 负责共用显示、首页/资金接入和盘点；独立任务分别负责货物页面与编辑器、结算页面与编辑器。所有人保留现有权限和 API 请求体，遇到新架构决策先报告。
