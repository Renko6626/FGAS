# 外部 Agent 连接页与接入引导

用户选择“先优化连接页和接入引导”，沿用“创建连接 → 复制接入说明交给 Agent → 核对身份和权限”的流程。

## 范围与取舍

优先给外部 Agent 一份完整接入说明，沿用现有公开指南，让客户端按自身格式配置。保留单独复制密钥、地址供手动配置；不新增客户端专用配置生成器、连通探测接口、权限或自动测试业务。

沿用现有本人凭据查看和管理 API；完整接入说明含密钥，按钮明确标注。密钥只在本人打开弹窗后读取，关闭、切换用户或卸载清空，不写本地存储。管理员仍不能读取他人密钥。
